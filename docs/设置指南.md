# 设置指南（中文）

## 原则

1. **密钥只留在本机**：钥匙串或官方 CLI 凭证文件。
2. **不要把密钥发到 Cursor 聊天、邮件、Issue、截图。**
3. AIQuoty **不会**自动解密浏览器 Cookie / Cursor Safe Storage。
4. 不会为了轮询配额而创建会计费的 AI 任务。

## Claude / Claude Code

1. 在终端完成 Claude Code 登录（官方流程）。
2. 确认存在 `~/.claude/.credentials.json` 且含 `claudeAiOauth.accessToken`。
3. 打开 AIQuoty，等待刷新。若 403，说明 token 可能缺少 `user:profile`；请重新登录 Claude Code，勿使用仅 inference 的 setup-token。
4. 可选：设置 → 连接 → 粘贴 OAuth access token 到钥匙串（本机操作）。

## Codex

1. 运行 `codex login`。
2. 确认 `~/.codex/auth.json` 含 `tokens.access_token`。
3. 纯 `OPENAI_API_KEY` **无法**读取订阅配额（应用会明确报错）。

## Cursor

任选其一（均为用户显式提供）：

- 在已登录的浏览器中打开 cursor.com → 开发者工具 → 复制请求 Cookie → 本机粘贴到 AIQuoty 设置；或
- 运行 `cursor-agent login`，确保 `~/.config/cursor/auth.json`（或 `~/.cursor/auth.json`）可读。

## Gemini CLI

1. 安装并登录 Gemini CLI。
2. 确认 `~/.gemini/oauth_creds.json`。
3. 若 access_token 过期，请重新登录 CLI（首版不内嵌 Google client secret 自动刷新）。

## Copilot

1. 创建具有 `read:user` 的 GitHub token（PAT 或 device flow）。
2. 仅在本机设置页粘贴到钥匙串。

## OpenRouter / Anthropic Admin

在设置页写入对应 API Key。数字会标为 **API 花费/余额**，不会混进订阅条。

## 本地日志

默认关闭。开启即表示同意扫描本机 JSONL；结果仅为 **本地观测估算**。

## 演示模式

设置 → 通用 → 演示模式：使用合成夹具预览 UI，不读真实密钥、不访问你的账户。
